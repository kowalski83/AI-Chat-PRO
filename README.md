# Roblox AI Bridge

Official Windows companion application for Roblox AI Chat PRO.

## Download

Download the latest Windows executable from the Releases section.

## Features

- Automatic Roblox Studio connection
- No manual pairing code
- AI agent integration
- Free and paid AI models
- Local AI support
- LM Studio integration
- API provider management

## Installation

1. Purchase Roblox AI Chat PRO from the Roblox Creator Store.
2. Download Roblox_AI_Bridge.exe.
3. Run the application.
4. Open Roblox Studio.
5. Configure your AI provider.

## Requirements

- Windows 10/11
- Roblox Studio
- Internet connection for online AI providers

## Pricing

Roblox AI Bridge is free to download.

Roblox AI Chat PRO is sold separately through the Roblox Creator Store.

Third-party AI providers may charge additional API usage fees.

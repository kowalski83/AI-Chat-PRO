# AI Chat PRO / AI Chat FREE

[Polski](README_PL.md)

An independent AI developer tool for Roblox Studio by **kowalski83**. The plugin supports code assistance, project editing and task automation. A local AI Chat Bridge connects to AI models.

## Editions

**PRO 4.9.35** — paid edition using customer-owned API keys and local models. Includes a Worker queue, Undo checkpoints and image attachments up to 20 MB.

**FREE 4.9.36** — planned no-charge edition with official SIWC, subject to OpenAI authorization.

Documentation describes PRO 4.9.35 source functionality; public EXE status and validation scope are explained in [limitations](docs/KNOWN_LIMITATIONS.md). The project is not sponsored or certified by OpenAI or Roblox.

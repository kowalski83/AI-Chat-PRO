## 🇬🇧 English

### About AI Chat PRO

AI Chat PRO is a commercial AI-powered development assistant designed for use with Roblox Studio.

It combines multiple artificial intelligence providers, local language models, autonomous coding agents, project management tools and backup systems in a single development environment.

### Download AI Chat PRO Bridge

[**⬇ Download AI Chat PRO Bridge for Windows**](https://github.com/kowalski83/AI-Chat-PRO/releases/latest/download/AI_Chat_PRO_Bridge.exe)

[View all releases](https://github.com/kowalski83/AI-Chat-PRO/releases)

AI Chat PRO Bridge is a companion application available at no additional charge to customers of the paid AI Chat PRO plugin.

Downloading Bridge does not grant ownership of the commercial plugin.

### Features

- Autonomous AI coding assistant.
- Luau script generation and editing.
- Project analysis and object management.
- Multiple AI providers.
- Local language model support.
- Free and paid AI model categories.
- API key management.
- Automatic Bridge detection.
- Automatic reconnection.
- Conversation history.
- Project snapshots and undo functionality.
- Backup management.
- Windows DPAPI protection for stored API keys.
- No manual pairing codes.
- No additional plugin subscription.

### Supported AI providers

| Provider | Status |
|---|---|
| LM Studio | Supported |
| OpenRouter | Supported – selected models |
| GroqCloud | Supported – selected models |

Additional AI providers may be introduced in future releases following technical and licensing verification.

Cloud AI services require users to meet the applicable provider's eligibility, age and account requirements.

### Installation

1. Purchase AI Chat PRO through the Roblox Creator Store once available.
2. Download AI_Chat_PRO_Bridge.exe.
3. Run the Bridge application.
4. Open Roblox Studio.
5. Launch the AI Chat PRO plugin.
6. Configure your preferred AI provider.
7. Select an available model and start working.

The plugin automatically detects the running Bridge application.

### System requirements

- Windows 10 or Windows 11, 64-bit.
- Roblox Studio.
- AI Chat PRO plugin.
- Internet access for cloud-based AI services.
- LM Studio installation for local models.
- A personal API key where required.

### Pricing

AI Chat PRO is a paid commercial product.

AI Chat PRO Bridge is included at no additional charge.

Third-party AI providers may charge separate fees for API usage. These fees are not included in the plugin purchase price.

### Security and privacy

Bridge communicates locally with the plugin using the loopback interface.

Stored API keys are protected using Windows DPAPI.

When using cloud AI services, prompts and relevant project data may be transmitted to the selected AI provider.

Local models can process AI requests locally, depending on their configuration.

Always review AI-generated code before publishing your projects.

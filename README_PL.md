# AI Chat PRO / AI Chat FREE
[English](README.md)

Niezależne narzędzie AI dla Roblox Studio, rozwijane przez **kowalski83**. Czat, pomoc w programowaniu, edycja projektu i automatyzacja korzystają z lokalnego programu Windows Bridge.

## Edycje
**PRO 4.9.35:** płatna edycja przewidziana do obsługi własnych kluczy API i modeli lokalnych. Kolejka Worker, punkty Undo i załączniki obrazowe (łącznie do 20 MB).

**FREE 4.9.36:** planowana bezpłatna edycja z Sign in with ChatGPT, zależna od autoryzacji OpenAI. Obecnie nieaktywna.

Dokumentacja opisuje wersję źródłową PRO. Testy natywne Windows, Studio i rzeczywistych usług nie zostały zakończone. Nie potwierdza zgodności aktualnie dostępnego EXE z opisem.

# AI Chat PRO
[English](README.md)

Niezależne narzędzie programistyczne AI dla Roblox Studio, rozwijane przez **kowalski83**.

## Możliwości

- Czat, analiza i edycja kodu projektu.
- Agent programistyczny, kolejka Worker i punkty Undo.
- Załączniki obrazowe PNG, JPEG i statyczny WEBP do 20 MB łącznie (maksymalnie trzy), zależnie od modelu i adaptera.
- Lokalny Bridge i indywidualne klucze API.

# Instalacja kandydata (tylko testy prywatne)
Zbuduj Bridge na Windows przez BUDUJ_EXE.bat z prywatnej paczki. Brak gotowego EXE. Importuj zgodny RBXMX w Studio. Uruchom Bridge w interaktywnej konsoli, wklej token sesji do panelu połączenia, połącz. Powtórz po restarcie. Przed uruchomieniem Bridge ustaw własne klucze przez KONFIGURUJ_KLUCZE.bat lub AI_Chat_PRO_Bridge.exe --configure-keys; Moduły pokazują tylko status; testuj ograniczone konto i projekt bez poufnych danych. Korzystaj z lokalnej inferencji, dopóki nie spełniono warunków chmury. Nie publikuj prywatnego ZIP, źródeł, korespondencji ani sekretów. Link publiczny aktualizuj dopiero po testach natywnej kompilacji; obecne wydanie GitHub może być starsze.

# Instalacja kandydata (tylko testy prywatne)
Zbuduj Bridge na Windows przez BUDUJ_EXE.bat z prywatnej paczki. Brak gotowego EXE. Importuj zgodny RBXMX w Studio. Uruchom Bridge w interaktywnej konsoli, wklej token sesji do panelu połączenia, połącz. Powtórz po restarcie. W Modułach ustaw własne klucze; testuj ograniczone konto i projekt bez poufnych danych. Korzystaj z lokalnej inferencji, dopóki nie spełniono warunków chmury. Nie publikuj prywatnego ZIP, źródeł, korespondencji ani sekretów. Link publiczny aktualizuj dopiero po testach natywnej kompilacji; obecne wydanie GitHub może być starsze.

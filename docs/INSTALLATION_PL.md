# Instalacja

1. Pobierz zgodne wersje pluginu i Bridge z oficjalnego repozytorium.
2. Uruchom Bridge. W jego oknie ustawień zapisz własne klucze API lub skonfiguruj adres lokalnego serwera modeli.
3. Przy pierwszym połączeniu skopiuj token parowania z Bridge do Studio. Kolejne uruchomienia korzystają z zapamiętanego parowania. W razie potrzeby zresetuj je w Bridge.
4. Wybierz dostawcę i model. Przetestuj połączenie na projekcie testowym.

Nie udostępniaj tokenu ani kluczy. Instrukcje dostawców: [konfiguracja](PROVIDERS_PL.md). Zakres dokumentacji: [README](../README_PL.md).

# Integracja OpenAI
PRO korzysta z oficjalnego Chat Completions API i indywidualnego klucza klienta, bez dostępu subskrypcyjnego ChatGPT. Klucze konfiguruje się lokalnie w Bridge. Tekst i obrazy są moderowane przed generowaniem, a tekst odpowiedzi przed przekazaniem do Studio. Negatywny wynik lub błąd moderacji zatrzymuje zadanie. Moderacja nie gwarantuje bezpieczeństwa ani nie weryfikuje wieku. Planowana edycja FREE wymaga autoryzacji SIWC.

https://developers.openai.com/api/docs/guides/moderation
https://developers.openai.com/siwc/quickstart

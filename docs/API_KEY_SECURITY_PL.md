# Dane uwierzytelniające
Magazyn Windows: %APPDATA%/RobloxStudioAIChatAgent/api_keys.json, koperta DPAPI bieżącego użytkownika, atomowa podmiana i migracja starego jawnego pliku przy odczycie. Natywny test Windows nie został tu wykonany. Środowisko deweloperskie poza Windows korzysta z jawnego JSON z ograniczonymi uprawnieniami. Zmienne środowiskowe są alternatywnym źródłem i nie są szyfrowane przez ten magazyn. Status klucza nie zwraca jego wartości. Obecny panel Moduły przyjmuje chwilowo jawny klucz i przesyła go przez lokalny HTTP do Bridge; nie można twierdzić, że klucz nigdy nie trafia do Studio. Wpisywanie klucza bezpośrednio w Bridge jest planowane. Usunięcie klucza z magazynu nie unieważnia go u dostawcy ani nie usuwa zmiennej środowiskowej. Brak wspólnego klucza wydawcy i centralnej bazy. DPAPI nie chroni przed złośliwym procesem tego samego użytkownika. Brak certyfikacji OpenAI.

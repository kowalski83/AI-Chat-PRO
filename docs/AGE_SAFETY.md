# Age assurance
The current PRO source requires a self-reported 18+ flag for cloud use in the plugin/Bridge. This is not independent age verification and is not sufficient evidence that the user is an adult. Intended audience: adults only. Local mode is not a proof of child safety. No ID collection is implemented. Before public release determine a privacy-preserving age assurance method and enforce it at the Bridge boundary, including expiration and revocation. Evaluate reporting, content filtering and applicable child-data rules. Prevent processing children's personal data; do not rely on declaration alone. ZDR is a provider-side eligibility/configuration issue, not a local toggle. Obtain clarification from platform and OpenAI; no claim that a particular method is sufficient.

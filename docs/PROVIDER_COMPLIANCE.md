# Provider policy
Current PRO technical allowlist: local, openrouter, groq, openai; exact cloud model IDs are defined in provider_policy.py, not guaranteed live availability. Blocked: Gemini, Cline (Cloud/CLI), NVIDIA NIM, Devin, ChatGPT OAuth. No environment opt-in for blocked providers. OpenAI API uses Chat Completions /v1/chat/completions and /v1/models with customer-owned keys; no subscription access. gpt-oss can run via local or authorized third-party hosting; no model weights bundled. Local aliases cannot prove license or locality. Actual pricing, retention, licenses and provider terms must be checked before release. Do not imply endorsement or unlimited free usage.

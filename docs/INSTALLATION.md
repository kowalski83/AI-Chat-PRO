# Installation

1. Obtain matching plugin and Bridge versions from the official repository.
2. Configure your own cloud API keys locally in Bridge, or start your local model server.
3. Start Bridge and enter its session token in Studio. Use a new token after restarting Bridge.
4. Select a provider and model. Test the connection with a test project.

Do not share tokens or API keys. See [provider setup](PROVIDERS.md) and [documentation scope](../README.md).

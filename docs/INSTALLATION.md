# Installation for the documented build
Build Bridge on Windows using BUDUJ_EXE.bat from the private source package. No EXE supplied for this integration. Import the matching RBXMX into Studio. Start Bridge in an interactive console, paste its session token into the connection panel, and connect. Repeat after restart. Before starting Bridge, configure customer-owned keys with KONFIGURUJ_KLUCZE.bat or AI_Chat_PRO_Bridge.exe --configure-keys; Modules only shows status; test with a restricted account and non-sensitive sample project. Use local-only inference unless cloud release requirements are satisfied. Do not publish the private ZIP, source, correspondence or secrets. Public download link must be updated only after verified native builds; current GitHub release may be older.

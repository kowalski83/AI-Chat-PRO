# Installation

1. Obtain matching plugin and Bridge versions from the official repository.
2. Start Bridge. Enter and save your own API keys in its settings window, or configure the local model server address.
3. On the first connection, copy the pairing token from Bridge into Studio. Subsequent launches reuse the pairing. Reset pairing in Bridge if needed.
4. Select a provider and model. Test the connection with a test project.

Do not share tokens or API keys. See [provider setup](PROVIDERS.md) and [documentation scope](../README.md).

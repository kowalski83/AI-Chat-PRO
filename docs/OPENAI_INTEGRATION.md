# OpenAI integration
PRO uses the documented Chat Completions API with customer-owned keys, not ChatGPT subscription access. Credentials are configured locally in Bridge. Text and images are moderated before generation; completed text is checked before delivery to Studio. Flagged or failed moderation stops the task. Moderation cannot guarantee safety or verify age. The planned FREE edition requires SIWC authorization.

https://developers.openai.com/api/docs/guides/moderation
https://developers.openai.com/siwc/quickstart

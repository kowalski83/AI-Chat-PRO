# Credentials
Windows store: %APPDATA%/RobloxStudioAIChatAgent/api_keys.json, DPAPI current-user encrypted envelope, atomic replace and migration of old plaintext on read. Native Windows round-trip has not been validated here. Non-Windows development uses restricted plaintext JSON. Environment variables remain an alternate source and are not encrypted by this store. Key status does not return key values. The current Modules UI accepts a plaintext key temporarily and sends it over loopback HTTP to Bridge; it is NOT correct to say the key never enters Studio. Direct credential entry in Bridge is a planned improvement. Deleting a stored key does not revoke it at the provider or remove an environment variable. No shared publisher API keys or central credential database. DPAPI is not a defense against malware running as the same user. No claim of OpenAI certification.

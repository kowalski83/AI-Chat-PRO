# SIWC — planned, disabled
FREE is intended to provide a no-charge path for eligible users to use their own ChatGPT plan. Application eligibility/registration and user consent for plan usage are separate requirements. No client ID, token flow or entitlement has been granted or implemented in this candidate. Do not reuse consumer session tokens or ordinary Codex CLI login as a commercial authentication mechanism. If authorized, implement the documented SIWC flow and Codex app-server configuration; securely store scoped credentials and support revocation. Do not rotate accounts to evade limits. FREE must not require a PRO purchase or charge for access to ChatGPT-plan usage.

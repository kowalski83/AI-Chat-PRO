# Dostawcy i modele

Wybierz usługę chmurową lub własny serwer modeli. Katalog wersji 4.9.35 obejmuje cztery adaptery i pięć sposobów uruchomienia. Modele chmurowe zależą od listy dopuszczonych oraz dostępności u dostawcy.

- [GroqCloud](providers/GROQCLOUD_PL.md)
- [LM Studio](providers/LM_STUDIO_PL.md)
- [Ollama](providers/OLLAMA_PL.md)
- [OpenAI API](providers/OPENAI_PL.md)
- [OpenRouter](providers/OPENROUTER_PL.md)

GPT-OSS 20B/120B to rodzina modeli, nie odrębna usługa. Dostęp zależy od katalogu dostawcy lub lokalnych wag. Pozostałe integracje, w tym logowanie subskrypcyjne ChatGPT, nie są dostępne w PRO.

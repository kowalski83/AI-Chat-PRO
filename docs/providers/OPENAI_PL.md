# OpenAI API

API chmurowe; własny klucz klienta; Chat Completions pod https://api.openai.com/v1; moderacja tekstu i obrazów przed generowaniem oraz tekstu po generowaniu. Bez logowania subskrypcyjnego.

## Konfiguracja i dane
Zatrzymaj Bridge, uruchom KONFIGURUJ_KLUCZE.bat, wybierz dostawcę i wpisz własny klucz. Uruchom Bridge, wklej token sesji w Studio, wybierz dostawcę i dostępny model z listy dopuszczonych. Koszty i retencja zależą od dostawcy i modelu. Wydawca nie udostępnia wspólnych kredytów ani abonamentu.

Negatywny wynik lub awaria moderacji zatrzymuje zadanie; moderacja nie potwierdza wieku. Obsługa obrazów zależy od modelu i adaptera. Zobacz [prywatność](../PRIVACY_POLICY_PL.md) i [instalację](../INSTALLATION_PL.md).

Dokumentacja oficjalna: https://developers.openai.com/api/docs

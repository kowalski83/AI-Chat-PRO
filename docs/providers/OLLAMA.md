# Ollama

Use the shared local adapter at http://127.0.0.1:11434/v1; disable cloud inference.

## Configuration and data
Start the separately installed model server and load a compatible model. Set the endpoint in Modules, refresh the catalog and select a model. No cloud API key is required by the local adapter. Hardware and model licenses are the user’s responsibility; a private address does not prove that inference stays local.

OpenAI moderation is not applied to this integration. Image support depends on the selected model and adapter. See [privacy](../PRIVACY_POLICY_EN.md) and [installation](../INSTALLATION.md).

Official documentation: https://docs.ollama.com/

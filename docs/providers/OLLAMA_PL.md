# Ollama

Użyj wspólnego adaptera lokalnego pod adresem http://127.0.0.1:11434/v1; wyłącz inferencję chmurową.

## Konfiguracja i dane
Uruchom oddzielnie zainstalowany serwer i załaduj zgodny model. Ustaw adres w Modułach, odśwież katalog i wybierz model. Adapter lokalny nie wymaga klucza chmurowego. Sprzęt i licencje modeli są odpowiedzialnością użytkownika; prywatny adres nie dowodzi lokalnego przetwarzania.

Moderacja OpenAI nie obejmuje tej integracji. Obsługa obrazów zależy od modelu i adaptera. Zobacz [prywatność](../PRIVACY_POLICY_PL.md) i [instalację](../INSTALLATION_PL.md).

Dokumentacja oficjalna: https://docs.ollama.com/

# OpenAI API

Cloud API; customer key; Chat Completions at https://api.openai.com/v1; text and image moderation before generation and text moderation after generation. No subscription login.

## Configuration and data
Stop Bridge, run KONFIGURUJ_KLUCZE.bat, select the provider and enter your own key. Restart Bridge, paste the session token into Studio, choose the provider and an available allowlisted model. Charges and retention are determined by the selected provider and model. No shared credits or subscription are supplied by the publisher.

A moderation rejection or failure stops the task; moderation is not an age check. Image support depends on the selected model and adapter. See [privacy](../PRIVACY_POLICY_EN.md) and [installation](../INSTALLATION.md).

Official documentation: https://developers.openai.com/api/docs

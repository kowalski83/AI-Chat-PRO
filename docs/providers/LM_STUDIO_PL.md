# LM Studio

AI Chat PRO integruje LM Studio z Roblox Studio za pomocą lokalnego programu AI Chat Bridge. Modele uruchamia użytkownik na własnym serwerze.

## Funkcjonalność

Pomoc w programowaniu, analiza kodu i wykonywanie zadań agenta w zakresie możliwości wybranego modelu. Obsługa obrazów zależy od modelu i adaptera; limit pluginu wynosi 20 MB łącznie.

## Konfiguracja

1. Uruchom LM Studio i załaduj zgodny model.
2. Uruchom lokalny serwer API.
3. W Modułach ustaw adres `http://127.0.0.1:1234/v1`.
4. Odśwież listę modeli i wybierz model.

## Bezpieczeństwo i prywatność

Adapter lokalny nie wymaga klucza chmurowego. Używaj zaufanego serwera; adres prywatny nie gwarantuje lokalnego przetwarzania. Bridge nie wykonuje dodatkowej moderacji treści tego adaptera.

Szczegóły: [prywatność](../PRIVACY_POLICY_PL.md), [instalacja](../INSTALLATION_PL.md).
